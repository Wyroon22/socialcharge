# SocialCharge 🔋

SocialCharge is a web application for tracking how daily social activities affect a user's energy, enjoyment, and social battery.

This project was built as a portfolio project using ASP.NET Core MVC, C#, Entity Framework Core, and Bootstrap.

---

## ✨ Features

- User registration and login
- Create, view, edit, and delete social activity records
- Track energy before and after each activity
- Track enjoyment score
- Track number of people involved in each activity
- Add personal notes for each activity
- Categorize activities such as Work, Study, Exercise, Friends, Family, and more
- Dashboard summary for activity statistics
- Energy status calculation such as Charged, Neutral, and Drained
- Responsive UI using Bootstrap
- User-specific data access using authentication

---

## 🧠 Project Concept

Some activities make people feel energized, while some activities make them feel drained.

SocialCharge helps users record their activities and understand which activities charge or drain their social energy.
